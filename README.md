# CivisLab · piloto

Páginas estáticas del piloto de CivisLab: entrada, mapa electoral de Antioquia (resultados oficiales 2019 y 2023; escenario 2027 con candidaturas ficticias), tablero territorial del Valle de Aburrá, fichas de actores políticos y mapa de veletas del Valle (datos oficiales con fuente) y maqueta de escucha del Pulso.

Generadas desde el repositorio privado `CivisLab/civislab-landing` (`hub/construir.py`). No editar a mano. Contacto: info.civislab@gmail.com
